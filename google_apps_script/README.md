# Google Sheets Apps Script App - Electricity Cost Calculator (חשבון חשמל)

This enables the Electricity Calculator Web App directly inside your Google Sheet (`חשבון חשמל`).

---

## How to Install in Google Sheets (2 Minutes):

1. **Open Your Google Sheet**:
   - Open your Google Sheet `חשבון חשמל` in Google Drive (or web browser).

2. **Open Apps Script Editor**:
   - In the top menu, click **Extensions** (הרחבות) ➔ **Apps Script**.

3. **Add Code Files**:
   - Delete any default text in `Code.gs` and paste the contents of [`Code.gs`](Code.gs).
   - Click the **+** button next to Files ➔ select **HTML** ➔ name it `Index` (so it becomes `Index.html`).
   - Paste the contents of [`Index.html`](Index.html).
   - Click the **Save** (💾) icon.

4. **Run or Deploy**:
   - Reload your Google Sheet! You will see a new custom menu at the top: **`חשבון חשמל ⚡`**.
   - Click **`חשבון חשמל ⚡`** ➔ **`פתח מחשבון דיירים (סרגל צד)`** or **`חלון מלא`**.
   - **(Optional Web App URL)**: Click **Deploy** ➔ **New deployment** ➔ Select type: **Web app** ➔ Set *Who has access*: **Anyone** ➔ Click **Deploy**. This gives you a standalone web link you can share with tenants!
